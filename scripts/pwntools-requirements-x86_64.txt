# Se generan con `pip download --python-version 3.14 --abi cp314` y sha256

# cada version de Python tiene su binario con su propio hash, asi que cambiar
# de Python obliga a rehacer este fichero entero.

# - unicorn 2.1.2 -> 2.1.1: la 2.1.2 no publica wheel para cp314. La 2.1.4 si
#   publica, pero pwntools 4.15.0 la excluye (exige >=2.0.1,!=2.1.3,!=2.1.4).
# - psutil 7.2.2 -> 7.1.1: el 7.2.2 no tiene wheel x86_64 para cp314.
# - packaging 26.3 -> 26.0: el snapshot de Ubuntu 26.04 solo tiene 26.0, y es
#   la que instala dpkg. Con 26.3 pip intenta desinstalar el 26.0 del sistema y
#   falla con "no RECORD file" porque lo instalo dpkg, no pip. pwntools pide
#   `packaging` sin fijar version, asi que 26.0 cumple.
